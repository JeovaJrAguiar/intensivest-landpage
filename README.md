# Intensivest — Landing Page 2027

Protótipo funcional em HTML, CSS e JavaScript, sem framework ou backend.

## Abrir
Abra `index.html` no navegador. Para servir localmente: `python3 -m http.server 8000` e visite http://localhost:8000.

## Funcionalidades
- Landing page responsiva com inscrição 2027 em destaque.
- Botão 'Acessar plataforma' apontando temporariamente para https://www.google.com.br/ (Academy Smart).
- Menu mobile, navegação por âncoras, FAQ e formulário demonstrativo.
- O formulário **não envia nem armazena dados**: prepara mensagem para copiar e enviar pelo Instagram.
- Fotografias ilustrativas e fontes são carregadas pela internet. Para produção, substituir por imagens autorizadas; a logomarca oficial enviada já está aplicada.

## Antes de publicar
Confirmar dados e textos com o Intensivest, fornecer logo e fotografias oficiais, decidir o destino real de inscrições, implementar backend seguro e política de privacidade/LGPD se for coletar dados, configurar domínio e URL definitiva do Academy Smart.

Logomarca oficial: `logo-intensivest.jpg`, usada no cabeçalho e no rodapé.

- Botão flutuante do WhatsApp oficial (+55 88 98215-1905) no canto inferior direito, com mensagem pré-preenchida sobre inscrições 2027.
